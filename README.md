# PathwayAnalytics

## About the Project

PathwayAnalytics is a personal Java project that I independently created from my own idea. It was not a homework assignment, class project, or instructor-assigned task. I wanted to challenge myself to take the Java concepts I was learning and use them to build something practical and useful.

The idea came from seeing how complicated planning a university degree can be. Students have to understand required courses, prerequisites, electives, mathematics and science requirements, general education requirements, and the total number of credits needed to graduate.

## What It Does

PathwayAnalytics is an interactive console-based program designed around the University of Wisconsin-Milwaukee (UWM) Bachelor of Science in Computer Science pathway.

The program helps users explore:

- Computer Science major requirements
- Mathematics requirements
- Natural science requirements
- Technical electives
- Applied mathematics electives
- General Education Requirements (GER)
- Free electives
- Course prerequisites
- C-or-higher requirements
- Graduation credit requirements
- Suggested academic pathways
- Career-focused elective options
- Course progress and graduation planning

## Why I Built It

I created this project because I wanted to go beyond small programming exercises and build a larger application around a real-world problem.

This project was my own idea and was developed independently. It was not assigned by an instructor and was not created as part of a homework assignment. I designed the concept, structure, and purpose of the project myself as a way to improve my programming and problem-solving skills.

## Java Concepts Used

The project uses fundamental Java concepts including:

- Scanner and user input
- Variables and data types
- If/else statements
- Switch statements
- Loops
- Boolean logic
- Methods
- Input validation
- Menu-driven navigation
- Conditional decision making

## Purpose

PathwayAnalytics represents my effort to turn a personal idea into a functioning Java application while strengthening my understanding of Java, software development, and problem solving.

## Disclaimer

PathwayAnalytics is a personal educational project and is not an official UWM advising or degree-audit system. Academic requirements may change, so students should always verify their degree requirements with official UWM resources and an academic advisor.
